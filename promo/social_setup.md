# Instagram и Facebook: что вставить при создании (всё готово к копированию)

Доступность имён я проверить не могу: это видно только при регистрации. Если имя занято, возьми следующий вариант.

## 1. Instagram (бизнес-аккаунт)

**Как создать (5 минут):**
1. Приложение Instagram → «Создать новый аккаунт» → по номеру телефона или e-mail (подтвердишь кодом).
2. Профиль → «Настройки» → «Тип аккаунта и инструменты» → «Перейти на профессиональный аккаунт» → «Бизнес».
3. Категория: «Образование» или «Услуги для образования».

**Имя пользователя (по порядку, что свободно):**
`kmj.mugalim`, `kmj_ksp_kz`, `kmj.presentation.kz`, `kmj.mugalimge`

**Название профиля (до 30 символов):**
`ҚМЖ · КСП · Презентация`

**Описание, казахский (до 150 символов):**
```
Мұғалімге: ҚМЖ + презентация – бір минутта 📄🎞️
Физика · Информатика · Қазақ тілі
👇 Үлгіні жүктеңіз
```

**Описание, русский:**
```
Учителю: КСП + презентация за минуту 📄🎞️
Физика · Информатика · Казахский язык
👇 Скачайте образец
```

**Ссылка в профиле:** `https://kmj-promo.vercel.app`
**Кнопка контакта:** «WhatsApp» (в настройках бизнес-профиля добавь номер для заказов).
**Аватар:** `promo/og.png` (квадрат 1080×1080).

**Первые 3 поста (сразу после создания):**
1. `ad_kk_post.png` + подпись «Вариант 1» из `ads.md`.
2. `ad_ru_post.png` + подпись «Вариант 2».
3. `ad_kk_45min.png` + короткая подпись: «Сабақ 45 минут, 7 кезең. Үлгіні WhatsApp-та жібереміз».

**Stories:** `ad_story.png` + стикер «Ссылка» на `https://kmj-promo.vercel.app`.

**Закреплённые подборки (Highlights):** «Үлгі / Образец», «Баға / Цена», «Сұрақ / Вопросы».

## 2. Facebook (страница, не личный профиль)

**Как создать (5 минут):**
1. Зайди в свой Facebook (нужен личный профиль; если его нет, создай его по своему телефону или e-mail).
2. Меню → «Страницы» → «Создать новую Страницу».
3. Название: `ҚМЖ · КСП · Презентация для учителей`.
4. Категория: «Образование».

**Описание страницы (казахский + русский):**
```
Мұғалімге арналған ҚМЖ мен презентация – бір минутта.
КСП и презентации для учителей Казахстана: физика, информатика, казахский язык и литература.
Үлгі / Образец: kmj-promo.vercel.app
```

**Кнопка на странице:** «Отправить сообщение WhatsApp» → номер для заказов.
**Обложка:** `promo/ads/ad_kk_45min.png` (обрежь по ширине).
**Первые посты:** те же три, что в Instagram.
**Связать страницы:** в Instagram → «Настройки» → «Центр аккаунтов» → добавь Facebook-страницу, тогда посты можно публиковать в обе сети сразу.

## 3. Правила, чтобы не заблокировали
- Не пиши «заработай» и не обещай доход.
- Не называй страницу «официальной» и не используй логотипы министерства.
- Не клади в посты чужие фамилии и фото учителей без согласия.
- Одну страницу = один владелец; пароль не передавай никому, включая меня.
